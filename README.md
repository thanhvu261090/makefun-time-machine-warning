A one-line warning label for a time machine — the one rule every traveller breaks first.

> "WARNING: Do not meet yourself — he owes you money, and he already knows where you live."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–120 characters, not only whitespace, a single printable line with no control characters, padding, or double spaces), and writes it to `/output/entry.txt` when run with `python3 main.py`.
